Política de privacidade do Agenda

Atualizada em 19 de outubro de 2026.

O que é o Agenda

Um aplicativo pessoal de calendário e tarefas, sem fins comerciais, mantido e usado pelo próprio desenvolvedor.

Dados do Google que o app acessa

Com a sua autorização (escopo https://www.googleapis.com/auth/calendar), o app lê e altera os eventos e a lista de calendários do Google Calendar da conta conectada: título, descrição, local, data e hora, repetição, lembretes e link de reunião. Também lê o e-mail da conta, para mostrar qual conta está conectada.

Para que esses dados são usados

Só para mostrar os seus eventos no app e para enviar ao Google as mudanças que você faz no app (criar, editar, excluir eventos). Os dados não são vendidos, não são usados para publicidade e não são usados para treinar modelos de inteligência artificial. O assistente do app roda num modelo de linguagem instalado no computador do próprio usuário; os dados não são enviados a serviços de IA de terceiros.

Onde ficam guardados

Numa cópia no próprio navegador (para funcionar sem internet) e no banco de dados do app, controlado pelo desenvolvedor. A autorização do Google (refresh token) fica só no servidor do app, sem acesso pelo navegador.

Compartilhamento

Os dados não são compartilhados com terceiros. O uso e a transferência de informações recebidas das APIs do Google seguem a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado.

Como revogar e apagar

Em Configurações → Google Calendar → Desconectar, o app revoga a autorização e apaga do app os calendários importados (eles continuam no Google). Você também pode revogar em myaccount.google.com/permissions. Para apagar todos os dados, escreva para o contato abaixo.
